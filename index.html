Презентация как жанр деловой коммуникации

Тема 1. Современная деловая риторика, этос, логос, пафос и качества публичной речи.

Цель

Научиться превращать анализ данных в убедительное деловое сообщение.

Инструменты

Python, pandas, Matplotlib, Seaborn, HTML-презентация.

Результат

Аналитические выводы, графики и рекомендации для руководства.

Что такое деловая презентация?

Деловая презентация — целенаправленное сообщение, представляющее проект, продукт, исследование или управленческое решение заинтересованной аудитории.

  • Имеет конкретную деловую цель.
  • Адаптируется под аудиторию.
  • Сочетает речь, данные и визуализацию.
  • Завершается выводом или призывом к действию.

Принцип: одна мысль — один слайд — один вывод.

Современная деловая риторика

Адресность

Речь строится под конкретную аудиторию и её интересы.

Логичность

Проблема → анализ → решение → выгоды → следующий шаг.

Доказательность

Тезисы подтверждаются данными, фактами и источниками.

Наглядность

График объясняет тенденцию быстрее, чем абзац текста.

Этос, логос и пафос

ЭлементСодержаниеВ презентации
ЭтосДоверие и авторитет спикераОпыт, источники, честность, корректность
ЛогосЛогика и доказательстваМетрики, сравнения, причинно-следственные связи
ПафосЭмоциональное вовлечениеКейс, ценность решения, образ результата

Классическая модель убеждения восходит к риторике Аристотеля. Подробнее: Ethos, Pathos and Logos.

Речевая культура делового человека

  • Точность формулировок и отсутствие двусмысленностей.
  • Понятность: термины объясняются примерами.
  • Чистота речи: без слов-паразитов и канцеляризмов.
  • Выразительность: интонация, паузы, акценты.
  • Информативность: новые и полезные для аудитории сведения.

Плохо: «мы что-то улучшили». Хорошо: «доля корректных прогнозов выросла с 78% до 86%».

Практикум: анализ онлайн-курсов

Задача — определить наиболее перспективную категорию курсов и подготовить рекомендацию для руководства.

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

data = {
    "course": ["Python для анализа данных", "Основы Data Science",
               "Машинное обучение", "Веб-разработка"],
    "category": ["Data Science", "Data Science",
                 "Data Science", "Разработка"],
    "students": [1200, 950, 640, 870],
    "rating": [4.7, 4.5, 4.8, 4.4],
    "completion_rate": [0.62, 0.55, 0.48, 0.51],
    "revenue": [1800000, 1320000, 1150000, 1010000]
}

df = pd.DataFrame(data)
df["revenue_per_student"] = df["revenue"] / df["students"]
print(df)

Расчёт метрик по категориям

summary = (
    df.groupby("category", as_index=False)
      .agg(
          courses=("course", "count"),
          students=("students", "sum"),
          avg_rating=("rating", "mean"),
          avg_completion=("completion_rate", "mean"),
          revenue=("revenue", "sum")
      )
      .sort_values("revenue", ascending=False)
)

summary["revenue_per_student"] = summary["revenue"] / summary["students"]
print(summary)

Метрика «выручка на студента» показывает коммерческую эффективность категории, а не только её масштаб.

Визуализация для слайда

plt.figure(figsize=(10, 5))

sns.barplot(
    data=summary,
    x="revenue",
    y="category",
    hue="category",
    palette="viridis",
    legend=False
)

plt.title("Выручка по категориям онлайн-курсов")
plt.xlabel("Выручка, руб.")
plt.ylabel("Категория")
plt.tight_layout()
plt.show()

Примеры и документация: Seaborn, Matplotlib, Kaggle Data Visualization.

Выводы и рекомендация

  • Категория Data Science демонстрирует наибольшую выручку.
  • Высокий рейтинг не гарантирует высокую завершаемость курса.
  • Для решения важны выручка, выручка на студента и качество обучения.
  • Рекомендация: расширить линейку Data Science-курсов и усилить проектную практику.

Формула вывода: наблюдение → причина → рекомендация.
